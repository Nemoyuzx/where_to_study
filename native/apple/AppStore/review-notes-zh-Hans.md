# App Review 备注（简体中文）

待提交构建：iOS `0.2.8 (75)`、macOS `0.2.8 (75)`。请审核各平台完成上传后的最新构建。

Where To Study 是由个人开发者维护的北邮非官方课程与空教室客户端，不由北京邮电大学运营，也不代表学校官方立场。应用不包含付费项目、订阅、广告、分析或行为跟踪 SDK。

## 无账号审核路径

1. 打开应用并进入“设置”。
2. 点按“浏览内置示例数据”。
3. 在设置中切换“跟随系统 / 简体中文 / English”，确认静态界面语言会立即变化；API 示例内容按设计保持原文。
4. 在“空教室”和“教学日历”页面检查示例课程、教室与日/周/月/年视图。日/周课程摘要可折叠，全天区的 `+N` 可打开作业和校内竞赛完整列表；月格和年视图日期详情也显示对应标记。
5. 在 iPhone 月视图选择日期并连续上滑；达到“日程已展开”后仍可滚动到作业、黄历和活动 DDL 卡片底部。
6. 在“教学日历”点按“导入系统日历”；应用会显示模拟同步结果，不申请日历权限或写入事件。
7. 在“设置”检查顶部双语参考提示、学科竞赛与校内竞赛通知独立开关，再开关每日课程摘要；示例模式不会申请通知权限或安排通知。
8. 在活动 DDL 详情右侧点按星标，再从“设置”进入独立“收藏管理”页检查和取消收藏；收藏只保存在本机。
9. iOS 与 macOS 均可从系统小组件图库添加“今日课程”，示例模式会向 App Group 写入虚构课表供 Widget 展示。
10. 从“教学日历”和“设置”分别进入“班车与重要事件查询”，切换顶部控件；班车使用示例时刻表，重要事件可搜索/分类并收藏会议，不包含作业。
11. 返回“设置”，点按“返回真实数据”退出示例模式。

示例模式只读取应用内置的虚构课程、教室和节假日数据，不连接北邮服务，不访问或覆盖 Keychain、真实课程/空教室缓存、系统日历或系统通知。iOS 与 macOS 仅为 Widget 审核向 App Group 写入虚构课表，退出示例模式后立即恢复本地真实课表快照。

## 真实数据路径

真实模式需要用户自己的北邮教务账号。账号和密码只保存在 Apple Keychain；应用通过 `https://jwglweixin.bupt.edu.cn` 请求个人课表及当天空教室。保存有效凭据且开启自动学期检测后，应用启动时会自动刷新一次个人课表，用于校验学期号和第一周周一。启动、回到前台或平台允许的每日 07:00 左右任务还可能自动刷新当天空教室。请求失败时不会切换到其他数据源。项目维护者不运营该服务，也不接收账号、密码、课表或空教室数据。

系统日历导入和每日 07:30 课程摘要均由用户主动触发；拒绝权限后其余功能仍可使用。

教学日历日期详情还会读取公开天气、黄历和活动截止信息。竞赛、会议与期刊专题来自 Contest DDL；独立的校内竞赛通知由服务器脚本从学校内部网站的公开通知页提取整理，再通过固定公开接口提供。班车查询通过固定 HTTPS 接口读取后勤部公开通知的结构化时刻表，不发送账号、课表或位置。用户还可选择公开 HTTPS JSON 自定义日程源；请求不携带教务凭据、Cookie 或个人数据并拒绝重定向。活动收藏保存完整本地快照，不上传或跨设备同步。课程作业卡仅在用户已保存凭据后，通过北邮 HTTPS 统一认证和云课堂接口临时读取作业，票据、Cookie、令牌与作业数据不写入磁盘。

## macOS 补充说明

关闭主窗口后应用按设计继续驻留菜单栏；可从菜单栏重新打开主窗口，或使用菜单中的“退出”完全结束。WidgetKit 扩展名为“今日课程”，从系统小组件图库添加后读取主应用通过 App Group 写入的本地课程快照。
