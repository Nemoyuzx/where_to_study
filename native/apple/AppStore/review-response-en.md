# macOS review response — sent 2026-09-08 21:31 +0800

Thank you for reviewing Where To Study. We have addressed the three issues in macOS version 0.2.8, build 85.

Regarding Guideline 4.1(b), Where To Study is independently developed and maintained. It is not operated by, affiliated with, sponsored by, or endorsed by Beijing University of Posts and Telecommunications. The university name is used only to explain which academic service and campuses the app currently supports, and to identify the source of relevant public notices. It is not used as the app's product name or icon. The app icon is a generic desk and calendar, not a university crest. We have removed the BUPT branding headings from the sidebar and calendar, used independent feature descriptions in the subtitle and removed university names from the keywords, and made the independent, unofficial identity visible on first launch and before account entry. The description now explicitly distinguishes service compatibility from university affiliation. We respectfully request review of the app in this clarified context. If a specific element still implies university endorsement, please identify it so we can address it directly.

Regarding Guideline 5.2.5, the installed application name, Finder bundle name, and application menu name are now “Where To Study.” The displayed name no longer includes “Mac.” The Bundle Identifier is unchanged.

Regarding Guideline 1.5, the Support URL now opens a dedicated help page with a direct maintainer email, feedback instructions, and common questions: https://github.com/Nemoyuzx/where_to_study/blob/main/SUPPORT.md . The app also includes an offline Help and Support page under Settings → About This App, with a selectable email address and a Contact by Email action. A GitHub account is not required to contact the maintainer by email.

The live review account remains in the private App Review Information fields. The app also provides an optional, clearly labeled fictional sample mode for review without a university account: open Settings > About This App > Browse Built-in Sample Data. You can inspect schedules, classrooms, calendar views, shuttle information, and important events. Help and Support is available under About This App.

Thank you for your time and reconsideration.
