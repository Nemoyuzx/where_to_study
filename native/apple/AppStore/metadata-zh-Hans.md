## iOS 描述

Where To Study 是面向北京邮电大学学生的独立非官方课程与空教室工具，不由北京邮电大学运营，也不代表学校官方立场。

主要功能：

• 查询西土城与沙河校区当天可用教室
• 按个人空闲节次和教学楼筛选空教室
• 获取个人课表并保存在本机，后续可离线查看
• 使用日、周、月、年视图浏览课程与法定节假日
• 月视图日期详情可连续滚动查看作业、黄历和活动截止信息
• 查看默认折叠的校区天气，并分别控制学科竞赛与校内竞赛通知
• 从教学日历或设置进入班车/重要事件查询，查看当天双向班次、搜索活动与会议并按 DDL 排序
• 收藏活动日程的完整本地快照，并在设置中集中管理
• 可接入符合公开规范的自定义 HTTPS JSON 日程源
• 将实际课程日期导入 Apple 日历，并更新已有课程避免重复
• 可选每天 07:30 在本机发送当日课程摘要
• 自动识别当前学期，也可手动调整学期与开学日期
• 可配置“今日课程”小组件的课程数量、地点与教师显示
• 公历周与教学周并列显示，跨学期时不混淆
• 支持浅色、深色、iPhone 与 iPad 自适应布局

隐私与安全：

学号和密码保存在 Apple Keychain。应用通过 HTTPS 连接北邮教务服务以获取课表或空教室；保存有效凭据且开启自动学期检测后，启动时会自动刷新一次个人课表以校验学期元数据。启动、回到前台或平台允许的每日 07:00 左右后台任务还可能自动刷新当天空教室。个人课表、空教室结果和设置保存在本机；项目服务端只整理公开班车和活动数据，不接收教务凭据或个人课表，也不包含广告、分析或行为跟踪 SDK。设置中可以查看完整隐私声明并清除本地数据。

应用内提供完全离线的内置示例模式，无需教务账号即可体验主要界面，并可安全模拟日历同步和课程提醒而不申请权限或写入系统数据。真实数据功能需要用户自己的北邮教务账号，且请求失败时不会切换到其他数据源。

源代码以 GPL-3.0-only 许可证公开：
https://github.com/Nemoyuzx/where_to_study

## 此版本的新内容

• 教学日历和设置新增统一查询入口，顶部切换“班车查询 / 重要事件”
• 班车按当天有效时段展示西土城与沙河双向班次、下一班和发车地点
• 重要事件支持名称、学校、标签和方向搜索，按类型/分类筛选并默认按 DDL 排序
• 学术会议和期刊专题进入教学日历；活动、会议和校内通知均可复用本地收藏

## TestFlight 测试说明

请重点检查：

1. 在“设置”中进入“浏览内置示例数据”，无需账号验证三个主要页面。
2. 在 iPhone 月视图选择日期，连续上滑到“日程已展开”后继续滚动，确认作业、黄历和活动 DDL 均可完整查看。
3. 在 iPhone 与 iPad 上切换日、周、月、年日历和横竖屏，并检查双语隐私声明及 GitHub 链接。
4. 在活动日程详情点按星标，进入设置的“收藏管理”确认可查看与取消；关闭来源后收藏仍保留。
5. iOS 与 macOS 分别检查“今日课程”小组件；macOS 另检查菜单栏今日/明日课程、键盘快捷键和关闭窗口驻留。
6. 分别从“教学日历”和“设置”进入综合查询，切换班车/重要事件；检查搜索分类、显示已结束和会议收藏。

测试版不要求测试者提供真实账号；真实数据路径只应使用测试者自己的北邮教务账号。
