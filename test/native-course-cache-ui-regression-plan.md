# Native cache and disclosure regression specification

Status: source specification only. No Node, JVM, Hypium, GUI, simulator or real-account verification was executed for this change.

- Warm restart: restore only a bounded valid DTO envelope whose opaque scope matches the current protected BUPT record or QM profile metadata. Render its original fetch time before the once-per-launch refresh. Course directory, assignment list and calendar share the existing client, authentication owner and in-flight requests.
- Cache validation: reject unknown fields, invalid schema/source/scope, duplicate IDs, impossible dates, invalid times, oversized rows/payloads, unauthorized QM URL fields and failed secure-scope migration. DTO validation precedes administrative Assignment filtering; same-title Quiz and ordinary undated coursework remain visible.
- Identity editing: an exact credential resave preserves scope. A real edit invalidates owner/generation and old scope before serial cache removal/new secure save. Late old publications cannot repopulate the accepted scope. A scope/delete failure must not bind stale identity data after a cold launch.
- Last-good: failed network refresh and QM partial failure preserve verified data and its original timestamp. A DTO write failure may show the new validated live data, but must show the explicit restart-cache warning, not claim a successful disk update.
- QM silent refresh: valid cookie first, saved credentials only under fresh explicit authorization. Guest entry may load only fixed plain login then fixed safe SAML once. Query links and SAML/MFA POST replay remain prohibited. MFA/error/unknown/deadline retires the silent owner without a window; explicit connection afterward uses a new owner and fixed dashboard GET. Feature Off retains credentials, cookies and business cache.
- Harmony profile fence: durable pending survives app restart. Blank-page engine cleanup, cookie acknowledgement and storage metadata verification precede readiness; business scope rotates again before clearing pending, so a failed earlier scope write cannot revive an old DTO file.
- Course/QM settings disclosure: info and chevron are separate equal-sized sibling controls; info never toggles the course. Expansion uses a top-clipped measured natural body, respects Reduce Motion and retains drafts/data. Off collapses QM details but manual management disclosure is still possible; connection remains gated.
- Shuttle: period and direction have independent default-folded page-session keys. Parent collapse retains child choices; body clipping does not compress natural text, fetch data or reset the snapshot. Full-table title, notice and source footer remain visible.
- Language: target app-owned resources, widget/notification local task acknowledgements, restored anchors and three stable frames are required before success. The circular/check stroke stays centered and two supported-device haptic attempts occur only for the current completion epoch. Failure, deadline, background, navigation or cleanup cancels without success; external OS presentation is not claimed.
