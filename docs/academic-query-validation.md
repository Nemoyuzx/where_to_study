# 成绩与考试安排：实现与验证记录

日期：2026-09-12。基于 0.2.9 源码开发，未提升版本号、推送代码、创建 Release 或上传商店。

## 使用方式

- 图形客户端：打开“查询 → 成绩”，可选择学校返回的学期或“全部学期”，以及最好、首次、全部记录。使用已保存的教务密码，而非独立教学云密码；未登录时提示进入现有账户设置。
- 获取／刷新个人课表会同时读取考试安排，复用同次教务登录；正常课程与考试源分别保留，日历读取有效结果。
- 同一天实际时间区间重叠时，考试优先于那一次课程；首尾相接不冲突，其他周次和原始课程不受影响。考试不提供课程删除入口。
- 无日期的考试只显示待定提示；日期已知但时间待定时在日期详情／全天区域显示，不虚构课时，也不排除可用教室时段。
- 考试读取失败不会丢弃成功的课表；仅同账号同学期可保留旧考试并明确提示，成功空结果会清除旧考试。账号变更、教务密码变更、清除数据之后拒绝在途旧响应。

- 学校真实接口：使用已有安全存储中的账户只读验证登录、当前学期、学校学期列表、成绩记录类型、当前／全部学期与考试端点。只输出结果状态、数量与字段类型，未保存私人分数或原始响应。
- SwiftUI：本地 Xcode macOS 191 项主要回归；后续相关调整定向 42 项通过。iPhone 13 项、iPad 15 项及追加英文 UI 检查通过。考试、成绩、Widget、导出、通知、账户缓存与月年投影均有覆盖。
- Android：253 项 JVM 测试、Lint、Debug APK 构建通过。专用模拟器手机、平板、折叠屏展开／闭合完成中英文及 1.3 字号视觉检查；查询页既有 5 项 UI 回归通过。
- HarmonyOS：212 项 Hypium 与 Release 构建／本地产物检查通过。额外保留 PC 字号下限检查；未具备可用鸿蒙设备／模拟器，不将编译或逻辑测试称为视觉实测。
- Rust：共享 Core 87 项、Tauri 201 项通过，3 项既有可选联网测试忽略，包含独立教务密码变更相关用例。包括精确分钟、半开区间、空／失败区分、同账号同学期回退、待定考试导出与禁止删除。
- React/Tauri：生产前端构建、211 项领域逻辑及跨平台契约测试通过；在 Edge 查看中英文成绩、零学分、文字／未公布成绩、周／月／年考试及只读考试详情。Windows/Linux 共用这套前端与 Rust 服务；未在本轮进行这两个操作系统的原生窗口实测。
- CLI／TUI：23／45 项单元与渲染测试通过，包括 40×22、80×24、120×32 的 Ratatui 界面；两个 Release 编译及帮助命令检查通过。CLI 支持 `grade-terms`、`grades --all-terms --records best`、`exams` 及 JSON；TUI 查询新增成绩模式。未用终端实际请求私人成绩，未进行 Linux 原生启动测试。

所有界面测试截图与考试样例均为明确的合成数据，不放入 README，也不包含私人成绩。所有测试不修改学校端课程、成绩、作业或考试安排。

## 仍需注意的边界

真实账号目前的考试 API 成功返回空数组，因此不能宣称已验证真实非空考试时间、考场或座位。解析器保守接受可确定的日期／时间，其余明确标为待定；后续遇到不同上游格式时应先用脱敏样例补回归，再扩展格式。

成绩只在内存显示／短期缓存，不计算猜测 GPA。终端的显式打印和 JSON 输出包含用户主动请求的数据，用户应避免公开分享该输出。
