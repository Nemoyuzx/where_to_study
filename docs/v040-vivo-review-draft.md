## 审核说明／体验路径（可粘贴）

Where To Study 是免费、开源、非盈利的学习与日程工具，由项目独立维护，不代表任何学校或机构。应用不创建项目账号，无广告或付费培训；首次启动需阅读隐私说明。公开班车、天气和重要事件无需机构账号即可使用。

审核可进入“设置→关于→浏览演示数据”体验示例课表和空教室，并查看语言、主题及本地界面。示例内容是虚构数据，不是用户的真实教务资料。真实课表、成绩、空教室和教学云作业需要用户本人的有效机构账户；QMplus 使用独立的官方账户。本次不提供私人登录账号或密码。

教学云平台密码可独立于教务密码保存。账号和密码的持久化只使用设备的系统安全存储，不写入普通设置、业务缓存或日志。QMplus 的保存／自动填写选项首次默认开启，并保留用户明确关闭的选择；预选开关本身不会保存凭据或建立授权。用户点击保存后，应用才将独立的 QMplus 登录资料加密保存到 Android Keystore 保护的安全记录，并按用户选择建立匹配的自动填写授权。

认证和数据请求直接发送到对应官方服务。教务查询目标为 `jwglweixin.bupt.edu.cn`；教学云通过 `auth.bupt.edu.cn` 认证，使用内存令牌请求 `apiucloud.bupt.edu.cn`；QMplus 在官方网页完成认证。这些目标仅用于说明审核时的技术流程，不作为学校授权或官方合作声明。验证码、MFA、风险确认和新协议由用户处理；应用不自动代为通过这些步骤。

QMplus 只读取用户已获授权的 EBU 课程及已发布 Assignment／Quiz 资料，不提交作业、开始测验或访问答案。其 Cookie 和网页存储由系统 WebView 引擎管理，与账号密码的安全存储分开；官方会话允许时可复用，但不保证永久登录或免于再次认证。关闭功能只暂停连接和同步；删除资料、退出并清除或清除本地数据会撤销旧连接并处理相应数据，失败时提示重试，不声称已经删除成功。

课程和作业缓存可跨重启恢复，成绩查询复用已获取结果。刷新失败或数据不完整时，应用保留并标明此前信息，不把旧结果当作新的成功数据。账号变更或清除资料会撤销旧的数据作用域，避免迟到结果回写。

首次读取作业建立静默基线，后续获取才对以前未出现的项目提醒；修改标题、截止时间或重复回调不会仅因此算作新作业。日、周视图的截止标记是时间点，不是排课时段，不为作业编造持续时长；原全天区域保留。仅依据明确提交状态显示未交红点，QMplus Quiz 状态不明确时不标红。

## Android 本地权限说明（可按审核字段粘贴）

实际权限以当前 AndroidManifest.xml 为准；此次资料不申请修改平台侧权限或扩展用户授权。

| 权限 | 用途与用户控制 |
| --- | --- |
| INTERNET | 通过网络读取公开班车、天气、校园信息及用户主动使用的官方教务／教学云／QMplus 功能。个人查询请求使用用户本人的已授权凭据。 |
| ACCESS_NETWORK_STATE、CHANGE_NETWORK_STATE | 判断联网状态并按用户的网络偏好选择应用请求路径，支持校内查询的网络适配；不用于采集通讯录或位置。 |
| READ_CALENDAR、WRITE_CALENDAR | 在用户主动选择导出课表或 DDL 时，选择日历并写入、识别应用导出的本地日历事件；已有授权时亦可读取系统节假日日历数据提供日期提示。用户未授权时不执行相应操作。 |
| POST_NOTIFICATIONS | 用户启用本地课程／考试提醒或每日课程摘要后显示通知。新增作业提醒是应用内弹窗，不以此替代系统通知授权。 |
| SCHEDULE_EXACT_ALARM | 用户选择准时本地提醒时请求系统相关能力；权限不可用时按当前系统允许的方式处理，不绕过系统限制。 |
| RECEIVE_BOOT_COMPLETED | 在设备重启后恢复用户已启用的本地提醒及受设置控制的任务安排。 |

运动效果使用设备可用的普通加速度传感器，不申请身体传感器权限；没有在 Manifest 中声明摄像头、麦克风、通讯录或定位权限。权限与功能说明应保持现有隐私政策、主体资质和审核表已有资料的一致性，不擅自替换其内容。
