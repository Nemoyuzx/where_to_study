# 0.2.9 移动端控件密度热修复

2026-09-12，按用户最新要求只发布布局修复。成绩／考试功能仍留在原工作区，未带入本次包。

## 改动

- Android 常规按钮、输入框、开关行与查询筛选恢复紧凑尺寸，基准高度统一为 32dp；移除先前增加的上下内边距。大字号文本可按内容增高，不强制截断。
- Android 恢复手机卡片 10dp 间隔、空教室卡片 12dp 内边距、两行节次格 46dp 基准与 4dp 间距；这些两行格不压成 32dp。恢复导航项 46dp、导航条左右 32dp 间距，保留移动选中背景、居中和自适应标签。
- Android／HarmonyOS 主题预设恢复紧凑的单行单列布局，保留所有配色、主题功能与选中样式。
- HarmonyOS 常规设置、输入框、开关行、查询控件从 36vp 等旧值统一为 32vp。未改日历单元格、两行课程、导航安全区或滚动逻辑。
- 不撤回隐私声明、备案信息、课程删除、独立教学云密码、班车布局、自动分页或底部避让修复。不改 Apple、Windows、Linux 代码或包。
