# 语言切换与资源生命周期审计

2026-10-03。切换界面语言应保留当前栏目、可见位置、未提交的输入、查询筛选和已加载数据；原始 API 内容不翻译。允许文字长度导致的正常重排，但不以“重新加载界面”为理由跳回顶部。保持原按钮尺寸、字体密度、课程接口和版本／签名配置。

## 实现边界

- Apple：保留 compact TabView 的身份，通过公开 UIKit 标题 setter 更新原有 tab item，不替换承载页面的 controller。更新任务有弱引用、代际检查和卸载取消；相同标题不重复更新。本地化 Bundle 缓存只有中英两份。宽屏侧栏的长英文标题允许换行，API 名称仍原样显示。
- Android：系统语言 Context 仍按 SDK 的 Activity 重建流程更新，但本次会话的纯数据、设置草稿与仓库留在内存中。服务使用 applicationContext，界面回调通过弱当前 owner 发布；配置重建仅解除观察者，真正退出才关闭 worker 与清理草稿。密码草稿不写 Bundle、视图自动保存或磁盘。滚动恢复使用稳定控件标识而非依赖翻译后文本的绝对像素位置；输入正文不参加界面文本翻译。
- HarmonyOS：固定选项使用稳定 ID，显示文字直接读取响应式语言状态；语言偏好串行写入，失败回退到最后已提交值，清除与迟到读取有代际保护。语言卡因英文换行累计位移时，依据实际布局变化一次性补偿 Scroll 偏移，离页／下一次操作撤销旧任务。查询筛选与公开班车快照由 Root 轻量会话持有，缓存五分钟、请求单飞；原数据生成时间和本地抓取时间分开，不把旧快照标为新数据。
- Tauri：共享前端维持页面身份和现有业务加载依赖。桌面托盘的语言、日期及本地编辑更新只读本地课表，不再在缓存为空时暗中发起登录／课表请求；明确点击刷新仍可获取，主界面正常获取课表后会本地更新托盘。重复选同一语言不重做菜单，迟到菜单任务不能覆盖较新的语言；手动获取过程中若被语言更新覆盖，保存成功后仅在确实发生竞争时锁外补一次本地发布，不再次联网。
