# 0.3.2 动画与生命周期复核

本次从安卓日／周视图课程摘要缺少折叠动画的问题出发，检查同类的展开、翻页、查询切换和首次弹窗。只修正有源码或运行证据的问题，不调整既有字体、控件尺寸、间距、主题颜色或数据源。测试数据为明确标记的示例，不使用个人凭据。

## 修正范围

| 平台 | 发现与处理 |
| --- | --- |
| Android | 天气点击原本重建整页，改为原视口高度／透明度／箭头动画；天气和空教室数据发布保留滚动容器与用户选择。日／周摘要复用已验证的可取消控制器。查询数据发布在入场完成后更新，旧回调不能复活旧页面。月视图动画检查当前视图及动画所有者，切换或离页取消。年详情明确配置原生淡入淡出。侧栏支持从中间宽度快速反向，旧完成回调不能落地旧目标。 |
| Apple | 手机课程摘要补齐内容进入／退出过渡；查询仅下方内容交叉淡入淡出，保留父层筛选与已有数据预热。天气尊重系统减弱动态。iPad 年详情保留日期旁位置并增加首次进入／退出淡入淡出。原有月／年分页 generation、取消和冻结快照机制不改写。 |
| Tauri | 天气保持挂载，通过裁切视口展开并在关闭时禁用交互。翻页最多保留一个离场快照和一个累计目标；离页或中途开启减弱动态时提交最后目标并清理。月折叠只测量／动画月历自身，不把下方详情一起压缩；取消旧定时器与帧回调。 |
| HarmonyOS | 课程行保留自然高度，动画只改变裁切视口；数据变更待动画结束后刷新。天气测量不受折叠视口约束，修正来源行裁切。移动与宽屏分页防止旧回调覆写最新目标、支持累计点击及离页提交。年浮层先挂载再淡入，关闭回调有所有者守卫。查询标题／选择条保持稳定，仅正文过渡。 |

动画逐帧回调不发起网络请求；原有仓库／模型获取逻辑继续负责数据，界面仅延后必要的重绘。展开与查询切段不增加登录或数据请求。

## 宿主电脑资源管理

用户强调的是电脑内存管理，本次不借此扩大到无关的应用缓存重构。重型构建串行执行，一次只运行一个模拟器；已经完成的两台 iOS 测试设备正常关闭，空闲 Gradle daemon 已停止。鸿蒙使用本次独立创建的临时实例，不修改既有实例或下载镜像。安卓使用只读测试实例，结束后正常关闭。不会关闭用户其它应用。

Android 构建限制 worker 数量且使用构建后退出的 daemon；前端测试限制并发并仅运行项目测试目录。报告前再核对本轮启动的构建进程与模拟器是否退出。系统交换空间不会因停止进程立即归零，不能以 swap 数值未清零认定清理失败。

收尾：两台已测 iOS 设备均 Shutdown；本轮安卓 Phone／Tablet 只读实例依次正常关闭；临时鸿蒙实例 `CodexMotion20261002` 通过官方 Emulator 正常停止并删除，其部署目录已不存在，既有八个用户实例和下载镜像保留。查询本项目 Hvigor 状态为 idle 后，仅用 `--stop-daemon` 停止当前项目的守护进程（未使用停止所有项目的选项），并确认其 Node／Java 子进程退出。没有遗留本轮 xcodebuild、Gradle daemon、Hvigor daemon 或模拟器工作进程。宿主可用内存比例在串行安卓测试期间约 75–77%，收尾约 76%；该瞬时值仅用于控制测试资源，不作为应用内存性能指标。
