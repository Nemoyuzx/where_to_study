## 审核说明与体验路径（可粘贴）

Where To Study 是免费、开源、非盈利的学习与日程工具，由项目独立维护，不代表任何学校或机构。应用不创建项目账号，无广告或付费培训。首次启动需阅读隐私说明；公开班车、天气、黄历和重要事件无需机构账号即可使用，显示数据仅供参考。

在设置页点击“浏览内置示例数据”，可以体验虚构课表、空教室和教学日历，再查看语言、主题及手机／展开布局。示例模式不连接真实教务服务，不展示或连接真实 QMplus 数据；它不能用来证明官方账户已经登录，也不能代替真实账户权限。本次不提供私人账号或密码。

需要查看本人真实课表、成绩、考试或教学云作业时，由用户保存自己的有效机构账户；QMplus 使用独立的官方账户。课程删除只影响本机展示，可恢复，不修改机构数据、作业截止时间或已经导出的系统日历事件。

## 登录、隐私与缓存说明（可粘贴）

账号和密码的持久化只使用 HarmonyOS ASSET 系统安全存储，不写入普通 Preferences、业务缓存或日志。教学云平台密码可以与教务密码分别保存，QMplus 的安全记录也与这两者分开。普通设置只保存功能偏好、授权标识和随机缓存作用域，不保存密码。

QMplus 保存界面的自动填写选项首次默认开启，并保留用户明确关闭的选择。预选开关本身不会保存凭据或建立授权；用户点击“安全保存 QMplus 登录资料”后，应用才写入 ASSET，并按用户选择建立与该记录匹配的自动填写授权。用户也可关闭自动填写，只安全保存资料。没有匹配授权时，不使用本应用保存的密码自动填写。系统密码管理器的建议属于用户另行授权的系统功能，应用不读取其密码库。

认证和个人查询直接访问对应官方服务：教务查询使用 `jwglweixin.bupt.edu.cn`；教学云通过 `auth.bupt.edu.cn` 认证，再用内存令牌访问 `apiucloud.bupt.edu.cn`；QMplus 在官方网页完成认证。这些域名仅用于说明技术目标，不作为学校授权或合作背书。验证码、MFA、风险确认、未知页面和新协议会交由用户处理，不自动代为通过，也不重放验证请求。

QMplus 仅只读获取用户已获授权的 EBU 课程和已发布 Assignment／Quiz 资料，不提交作业、不启动测验，也不访问答案。其 Cookie 和网页存储由系统 ArkWeb 引擎管理，和 ASSET 中的账号密码分开，不导出到普通业务快照、日志或项目服务器。官方允许的会话可在本机复用，但平板、二合一等设备的会话 Cookie 可能不持久，官方仍可要求重新登录或 MFA，不能保证永久会话。

关闭 QMplus 功能会暂停连接与同步，保留安全记录、网页数据和课程缓存。更换 QMplus 身份、退出或清除资料时，应用先撤销旧连接并设置清理标记；需要重启或重试时会提示用户。只有完成相应的网页数据清理确认后才重新访问官方页面，不能把保存新密码当作旧会话已经删除。

课表、空教室、偏好及收藏保存在设备上。课程、作业业务缓存保留原获取时间，启动先显示缓存，再由共享数据入口更新；失败或部分更新时保留并标明此前资料。成绩只在当前运行进程内按账号、学期和记录类型保留，不写入课表缓存；考试安排随课表缓存在本机。清除本地数据不会删除官方服务或第三方保有的记录。

## 鸿蒙权限说明

以下六项来自 `native/harmony/entry/src/main/module.json5` 的实际声明，没有把 Android 权限套用到鸿蒙。

| 权限 | 用途与用户控制 |
| --- | --- |
| `ohos.permission.INTERNET` | 读取公开信息，或按用户选择访问官方教务、教学云、QMplus 服务。公开请求不附带个人凭据。 |
| `ohos.permission.GET_NETWORK_INFO` | 判断连接状态，处理离线、网络不可用等情况。 |
| `ohos.permission.PUBLISH_AGENT_REMINDER` | 使用系统提醒代理安排用户启用的本地课程／考试提醒与每日课程摘要。新增作业提示是应用内弹窗，不是向外发送消息。 |
| `ohos.permission.VIBRATE` | 在日历选择、翻页等用户操作中提供轻触反馈，调用受系统权限与设备能力限制。 |
| `ohos.permission.READ_CALENDAR` | 在用户使用日历同步功能时读取、识别应用导入的个人课程事件；模块将使用场景限定为 `EntryAbility` 的 `inuse`。 |
| `ohos.permission.WRITE_CALENDAR` | 在用户主动导出课表或 DDL、且授权后写入系统日历；模块将使用场景限定为 `EntryAbility` 的 `inuse`。 |

当前模块没有声明定位、摄像头、麦克风或通讯录权限。天气按用户所选校区对应行政区查询，不使用 GPS。运动显示使用设备可用的普通传感器，不以此读取身体健康信息；系统不提供相应能力时按当前界面逻辑处理。
